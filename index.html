Seamless Cross Application User Integration
Supporting Standards: OAuth 2 Token Exchange and SCIM


This will push integrations of independent vendors in the Open Source eco-system massively forward. Use cases like our super deep bi-directional integration with Nextcloud will be so much smoozer App suits like openDesk will only find adoption if cross application user integration is solved. It is complex and expensive. It needs to get simpler and out of our way. Fortunately there are the open standards for OIDC and Token Exchange for delegated access but also for user provisioning vis SCIM.
